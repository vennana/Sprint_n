# Final_Project
## Структура

- `pages/` — Page Object Model (классы страниц, без прямых обращений к driver)
- `pages/locators.py` — все локаторы элементов
- `pages/base_page.py` — базовые методы взаимодействия с браузером
- `tests/` — тесты, разделённые по функциональности (4 модуля)
- `data/test_data.py` — тестовые данные и константы
- `conftest.py` — фикстуры драйвера и предусловий

## Предусловия

Используются фикстуры:
- `driver` — запуск браузера и открытие главной страницы.
- `route_picker_page` — маршрут построен, открыт блок выбора маршрута.
- `taxi_order_page` — открыта форма заказа такси в режиме «Быстрый».
